# Hackathon Team — Git & GitHub Sync Check

Welcome to the repository! Before we start building, everyone needs to complete this quick check to verify your repository access, local Git setup, and Pull Request workflow.

---

### 📋 What You Need to Do

1. **Clone the Repository**
   Clone this repository onto your local machine.

2. **Create Your Own Branch**
   Create and switch to a new branch named after yourself *(do not push directly to `main`)*.

3. **Add Yourself to the Team Roster**
   Edit this `README.md` file, scroll down to the **Team Roster** section below, and add a new bullet point with your name and role following the existing format.

4. **Commit & Push Your Branch**
   Commit your changes to your personal branch and push that branch to GitHub.

5. **Open a Pull Request (PR)**
   Create a Pull Request merging **your branch** into `main` with the title:
   `This pull request is from [Your Name]`

---

### 🛡️ Team Git Ground Rules
* **Never push directly to `main`:** Always work on a separate branch and merge via Pull Request.
* **Pull before starting:** Always sync your local `main` branch before creating a new feature branch.
* **Keep branches focused:** Use clear branch names for features or fixes so reviews and merges stay fast.
